# مرجع الأساليب التجريدية

اقرأ هذا الملف عند اختيار الأسلوب التجريدي المناسب للوحة المستخدم.

## الأساليب السبعة

| الأسلوب | الاسم العربي | متى تختاره | شدة مقترحة |
|---|---|---|---|
| `geometric` | تجريد هندسي | لوحات معمارية، مدن، تصاميم جرافيكية؛ عندما يريد المستخدم إيقاعًا صارمًا وأشكالًا واضحة | 0.5 – 0.8 |
| `cubist` | تجريد تكعيبي | بورتريه، طبيعة صامتة، مشاهد فيها عناصر مميزة تستحق التفتيت إلى مستويات | 0.5 – 0.75 |
| `lowpoly` | مضلّعات | مناظر طبيعية، حيوانات، صور شخصية؛ تجريد أنيق يحافظ على قابلية التعرّف | 0.3 – 0.6 |
| `faceted` | تجريد مُسطَّحي | بورتريه ولوحات زخرفية عندما يجب أن تبقى المعالم والزخارف واضحة؛ مثلثات كبيرة مع إبراز خطوط الزخرفة الأصلية | 0.35 – 0.6 |
| `expressionist` | تجريد تعبيري | لوحات عاطفية، غروب، مشاهد درامية؛ عندما يريد المستخدم طاقة وحركة | 0.6 – 0.9 |
| `colorfield` | حقول اللون | أي لوحة غنية بالألوان؛ عندما يريد المستخدم الهدوء والجوهر اللوني فقط | 0.5 – 0.8 |
| `flow` | تجريد انسيابي | بحر، سماء، موسيقى، مشاهد حالمة؛ تجريد غنائي يذيب المعالم تدريجيًا | 0.5 – 0.85 |

## كيف تختار الأسلوب

1. **اسأل المستخدم أولًا** إن لم يحدد أسلوبًا: اعرض عليه الأساليب الستة بجملة واحدة لكل منها.
2. **إن طلب المستخدم دفعة استكشافية**: ولّد 3 أساليب متنوعة على الأقل (مثلًا: `cubist` + `expressionist` + `colorfield`) ببذور مختلفة ليقارن.
3. **طابِع اللوحة الأصلية يوجّه الاختيار**:
   - ألوان صارخة وتباين عالٍ ← `expressionist` أو `geometric`
   - تدرجات هادئة ومساحات واسعة ← `colorfield` أو `flow`
   - تفاصيل دقيقة ووجوه ← `lowpoly` أو `cubist` بشدة متوسطة

## شدة التجريد (intensity من 0 إلى 1)

- **0.2 – 0.4**: تجريد خفيف، اللوحة الأصلية واضحة المعالم.
- **0.5 – 0.7** (الافتراضي 0.65): توازن بين روح اللوحة والتجريد — مناسب لمعظم الطلبات.
- **0.8 – 1.0**: تجريد عميق يقترب من العمل الجديد كليًا.

## البذرة (seed)

- نفس البذرة + نفس الباراميترات = نفس النتيجة دائمًا (قابلية إعادة الإنتاج).
- لتوليد تنويعات من نفس اللوحة والأسلوب: غيّر البذرة فقط (مثلًا 1، 2، 3).
- سجّل البذرة المستخدمة دائمًا في البطاقة الفنية لتتمكن من إعادة توليد العمل.

## أمثلة أوامر

```bash
# تجريد تكعيبي افتراضي
python3 scripts/abstract.py input.jpg -o output.png --style cubist

# تجريد تعبيري عميق
python3 scripts/abstract.py input.jpg -o output.png --style expressionist --intensity 0.85 --seed 7

# حقول اللون بإخراج PDF للطباعة
python3 scripts/abstract.py input.jpg -o output.pdf --style colorfield --size 1600

# دفعة استكشافية بثلاثة أساليب
python3 scripts/abstract.py input.jpg -o out_cubist.png --style cubist --seed 1
python3 scripts/abstract.py input.jpg -o out_expr.png --style expressionist --seed 2
python3 scripts/abstract.py input.jpg -o out_color.png --style colorfield --seed 3
```

## ملاحظة عن الأصالة

هذه الأساليب مستوحاة من مدارس الفن التجريدي العامة (التكعيبية، التعبيرية التجريدية،
حقول اللون...). لا تنسب الناتج لأي فنان بعينه، ولا تحاول محاكاة لوحة محددة لفنان
معاصر أو محمي الحقوق — التجريد يُبنى دائمًا من لوحة المستخدم نفسه وألوانها.
